BMaGlass Pay for Odoo

Same BMaGlass account. Same ZMW / USD wallets.

This provider connects Odoo to your existing BMaGlass Pay account through the BMaGlass Pay developer API. At checkout the buyer is redirected to a hosted BMaGlass payment page and pays wallet-to-wallet; settlement is confirmed automatically by scheduled reconciliation, and an HMAC-verified webhook endpoint receives BMaGlass's signed events.

Honest limits: a live API key (bmp_live_...) is required to take payments — BMaGlass test keys are read-only by design because the platform has no test-mode ledger. Only ZMW and USD are supported, the currencies BMaGlass wallets hold; no exchange rate is ever invented.
